# FxSoundStarter
This tiny app (128kb optimized, dependent on NET 8) checks for fxsound.exe, kills it (hits on it multiple times with a hammer until there is only noise), waits a bit, then restarts it with a chosen audio device as attribut. As I have several sound cards and FxSounds reliably fails to remind the one I want to use, I start a taskjob with this EXE
